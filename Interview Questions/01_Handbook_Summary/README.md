# Machine Learning Interview Handbook Summary

Справочные материалы для углубленной подготовки к собеседованиям по Machine Learning. Все материалы представлены в формате LaTeX для удобной печати и чтения.

## Структура репозитория

- **Decision_Trees_LaTeX/**: Фундаментальные свойства деревьев, жадный алгоритм, критерии информативности, регуляризация и оптимизации (гистограммный метод).
- **GBDT_Materials/**: Глубокий разбор градиентного бустинга. Сравнение с бэггингом, математика функционального градиентного спуска, разбор XGBoost, LightGBM и CatBoost.
- **CrossValidation_LaTeX/**: Методы валидации (k-Fold, Stratified, LOO), кривые обучения и диагностика Bias-Variance tradeoff.
- **Metrics_LaTeX/**: Метрики классификации (ROC-AUC, PR-AUC) и регрессии (MSE, MAE, R2).
- **ML_Linear_Models_LaTeX/**: Линейная и логистическая регрессия, регуляризация (L1/L2), градиентный спуск.
- **Hyperparameters_LaTeX/**: Оптимизация гиперпараметров (GridSearch, RandomSearch, Bayesian Optimization).
- **Metric_Methods_LaTeX/**: Метрические методы (k-NN, ядра).

## Основные темы
- Разница между Bias и Variance.
- Математика градиентного бустинга.
- Сравнение лидеров рынка (CatBoost, LightGBM, XGBoost).
- Интерпретация моделей (Feature Importance, Permutation Importance).
- Правильная постановка экспериментов и кросс-валидация.
