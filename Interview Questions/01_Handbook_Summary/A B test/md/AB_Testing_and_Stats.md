## 1. Работа с библиотекой Pandas

`pandas` --- основной инструмент для манипуляции табличными данными в Python. Эффективная работа с ней требует понимания внутреннего устройства её объектов (Series, DataFrame) и особенностей работы с памятью.

### Чтение данных: `read_csv`

Метод `pandas.read_csv` используется для загрузки табличных данных из файлов с разделителями. Основные аргументы, знание которых часто проверяется на собеседованиях:

*   **`filepath_or_buffer`**: Путь к файлу (локальный или URL) или объект типа buffer (например, `StringIO`).
*   **`sep` (или `delimiter`)**: Символ-разделитель колонок (по умолчанию `','`). Для файлов с разделителем-табуляцией используется `'\t'`. Регулярные выражения поддерживаются при использовании параметра `engine='python'`.
*   **`header`**: Номер строки (0-indexed), используемой в качестве имен колонок. По умолчанию `header=0`. Если файл не содержит заголовков, передают `header=None`.
*   **`names`**: Список названий колонок. Используется в паре с `header=None` или для переопределения существующих заголовков (в сочетании с `header=0`).
*   **`index_col`**: Столбец (или список столбцов для мультииндекса), который станет индексом строк.
*   **`usecols`**: Список столбцов для считывания. Оптимизирует расход оперативной памяти, отсекая ненужные данные на этапе загрузки.
*   **`dtype`**: Словарь с типами данных для конкретных колонок (например, `{'id': 'int32', 'price': 'float32'}`). Позволяет избежать автоматического приведения типов и сэкономить память.
*   **`na_values`**: Список или словарь значений, которые следует распознавать как `NaN` (например, `['NA', 'null', '?', '-']`).
*   **`parse_dates`**: Булев флаг или список столбцов, которые необходимо преобразовать в формат `datetime64`.
*   **`chunksize`**: Размер чанка (число строк) для итеративного чтения больших файлов. Возвращает объект `TextFileReader`, позволяющий обрабатывать данные по частям без переполнения RAM.

```python
import pandas as pd

# Чтение только необходимых колонок с явным указанием типов и парсингом дат
df = pd.read_csv(
    "data.csv",
    sep=";",
    usecols=["user_id", "timestamp", "revenue"],
    dtype={"user_id": "int64", "revenue": "float32"},
    parse_dates=["timestamp"],
    index_col="user_id"
)
```

### Индексы и селекция: `index`, `loc`, `iloc`

Индекс в Pandas (`Index`) --- это не просто номера строк, а хэш-таблица (или B-дерево), которая обеспечивает быстрый поиск элементов за время $O(1)$. 
*   **Преимущества**: Быстрое объединение таблиц (`join`/`merge`), эффективная фильтрация и выравнивание данных при математических операциях.
*   **Смена индекса**: Метод `set_index()` делает колонку индексом, а `reset_index()` возвращает индекс обратно в столбцы, создавая стандартный автоинкрементный числовой индекс.
*   **Мультииндекс (MultiIndex)**: Иерархический индекс строк или колонок. Позволяет работать с многомерными данными в плоском представлении.

**Разница между `.loc` и `.iloc`**:
*   **`.loc`**: Производит выборку элементов исключительно по **меткам (labels)**. Левая и правая границы среза **включаются** в выборку (например, `df.loc['a':'c']` вернет строки с именами 'a', 'b' и 'c').
*   **`.iloc`**: Производит выборку исключительно по **целочисленным позициям (indices)** (0-indexed). Правая граница среза **исключается** (например, `df.iloc[0:3]` вернет строки на позициях 0, 1 и 2).

```python
# Выборка по меткам (включая границу 'user_200')
df_loc = df.loc['user_101':'user_200', 'revenue']

# Выборка по позициям (первые 5 строк, первые 2 колонки)
df_iloc = df.iloc[0:5, 0:2]
```

### Быстрый анализ данных: `describe` и `value_counts`

*   **`describe()`**: Возвращает описательную статистику. Для числовых признаков: количество (`count`), среднее (`mean`), стандартное отклонение (`std`), минимум, квантили (25%, 50%/медиана, 75%) и максимум.
    *   *Параметр `include='all'`*: Позволяет анализировать как числовые, так и категориальные признаки одновременно. Для категориальных колонок выводятся уникальные значения (`unique`), мода (`top`) и частота моды (`freq`).
    *   *Ограничения*: Не улавливает нелинейные зависимости, сильно искажается под влиянием выбросов (при расчете `mean` и `std`).
*   **`value_counts()`**: Возвращает Series, содержащий частоты уникальных значений.
    *   *Аргументы*: `normalize=True` (доли вместо абсолютных значений), `dropna=False` (учитывает пропуски `NaN` при подсчете частот), `bins` (автоматически группует числовые данные в интервалы, аналог гистограммы).

```python
# Полный анализ данных, включая категориальные
summary = df.describe(include='all')

# Получение долей уникальных категорий с учетом пропусков
category_shares = df['category'].value_counts(normalize=True, dropna=False)
```

### Группировка и агрегация: `groupby` и `agg`

Концепция **Split-Apply-Combine** лежит в основе `groupby`:
1.  **Split**: Разбиение данных на группы по определенным критериям.
2.  **Apply**: Применение агрегирующей функции к каждой группе независимо.
3.  **Combine**: Объединение результатов в единый DataFrame/Series.

Метод `agg()` (или `aggregate()`) позволяет применять несколько функций агрегации одновременно:
```python
# Использование словаря для дифференцированной агрегации
grouped = df.groupby('group').agg({
    'revenue': ['sum', 'mean'],
    'purchase_count': 'max'
})

# Именованное агрегирование (Named Aggregation) - предотвращает появление мультииндекса в колонках
flat_grouped = df.groupby('group').agg(
    total_rev=pd.NamedAgg(column='revenue', aggfunc='sum'),
    avg_rev=pd.NamedAgg(column='revenue', aggfunc='mean')
)
```

> [!NOTE]
> Использование стандартных строковых агрегаторов ('mean', 'sum') работает значительно быстрее кастомных lambda-функций, так как под капотом Pandas вызывает оптимизированные C-функции (Cython). Передача лямбд заставляет Python делать итерации в цикле на уровне интерпретатора.

### Сводные таблицы: `pivot_table`

Метод `pivot_table` --- это высокоуровневый интерфейс для построения сводных таблиц.
*   **Основные параметры**:
    *   `values`: Колонка для агрегирования.
    *   `index`: Колонка(и), значения которой станут индексами строк новой таблицы.
    *   `columns`: Колонка(и), значения которой станут названиями новых столбцов.
    *   `aggfunc`: Функция агрегации (по умолчанию `'mean'`).
    *   `margins`: Булев флаг (по умолчанию `False`), добавляющий строки и столбцы `All` с итоговыми значениями агрегации по всей таблице.
*   **Сравнение с `groupby`**: Любой `pivot_table` может быть выражен через `groupby` с последующим применением `unstack()`. Однако `pivot_table` предоставляет более читаемый декларативный синтаксис именно для двумерных таблиц.
*   **Сравнение с `pivot`**: `pivot` используется исключительно для изменения размерности таблицы без агрегирования (вызовет ошибку `ValueError`, если для комбинации индекса и колонки найдутся дубликаты). `pivot_table` умеет работать с дубликатами за счет наличия `aggfunc`.

```python
pivot_df = df.pivot_table(
    values='revenue',
    index='user_segment',
    columns='country',
    aggfunc='sum',
    margins=True
)
```

### Работа с пропусками: `isna` и `fillna`

Пропуски в данных обозначаются как `NaN` (Not a Number) для числовых типов или `None`/`NaT` (Not a Time) для временных.

*   **`isna()` vs `isnull()`**: Это **абсолютные синонимы**. Функция `isnull()` была добавлена для схожести с синтаксисом языка R, в то время как `isna()` логически продолжает имя константы `NaN`.

**Стратегии обработки пропусков**:
1.  **Удаление строк/столбцов (`dropna()`)**:
    *   *Параметры*: `axis` (0 для строк, 1 для столбцов), `how` (`'any'` --- удалить, если есть хоть один пропуск, `'all'` --- удалить, только если все значения пропущены), `thresh` (задает минимальное количество заполненных ячеек для сохранения), `subset` (список колонок для поиска пропусков).
    *   *Опасность*: Может привести к критической потере данных и вызвать **смещение выборки (selection bias)**, если пропуски распределены не случайно.
2.  **Заполнение константой или логическим сдвигом (`fillna()`)**:
    *   `method='ffill'` (forward fill): копирует последнее известное значение вперед. Полезно для временных рядов.
    *   `method='bfill'` (backward fill): копирует следующее известное значение назад.
3.  **Заполнение статистиками (Mean, Median, Mode)**:
    *   *Критическая опасность (Data Leakage)*: Расчет среднего значения по всему датасету до его разбиения на Train/Test выборки приводит к утечке информации из теста в трейн. **Правильный подход**: рассчитать статистику только на Train, и заполнить ею как Train, так и Test.
    *   *Искажение распределения*: Заполнение средним значением искусственно стягивает дисперсию к нулю и искажает истинную форму распределения признака.
4.  **Продвинутое восстановление**: Использование `KNNImputer` (на основе k-ближайших соседей) или `IterativeImputer` (MICE --- восстановление на основе цепных уравнений регрессии).

```python
# Имитация правильного workflow без Data Leakage
from sklearn.model_selection import train_test_split

train, test = train_test_split(df, test_size=0.2, random_state=42)

# Вычисление медианы строго на Train выборке
train_median = train['age'].median()

# Заполнение вычисленной медианой обеих выборок
train['age'] = train['age'].fillna(train_median)
test['age'] = test['age'].fillna(train_median)
```

## 2. Преобразования и масштабирование признаков

Многие алгоритмы машинного обучения чувствительны к масштабу входных данных. Без масштабирования признаки с большими абсолютными значениями будут доминировать при обучении.

### Z-score (Стандартизованная оценка)

Математическое определение Z-score для случайной величины $X$:
$$Z = \frac{X - \mu}{\sigma}$$
где $\mu$ --- математическое ожидание (среднее значение), а $\sigma$ --- стандартное отклонение генеральной совокупности.

*   **Статистический смысл**: Показывает, на сколько стандартных отклонений наблюдаемое значение отклоняется от среднего. Для нормального распределения $N(0, 1)$ выполняется правило трех сигм: 99.73% всех значений лежат в интервале $[-3, 3]$.
*   **Детекция выбросов**: Значения с $|Z| > 3$ часто классифицируются как аномалии.
*   **Где НЕЛЬЗЯ использовать Z-score**:
    1.  *Распределения с тяжелыми хвостами или мультимодальные*: Среднее и стандартное отклонение некорректно описывают форму таких данных.
    2.  *Малые выборки*: Оценки выборочного среднего и выборочной дисперсии нестабильны.
    3.  *Наличие экстремальных выбросов (Masking Effect)*: Экстремальный выброс смещает среднее значение $\mu$ в свою сторону и сильно раздувает дисперсию $\sigma^2$. В результате сам выброс получает меньшее значение Z-score, а другие умеренные выбросы становятся «незаметными».

> [!TIP]
> Решение проблемы выбросов при Z-масштабировании --- использование **Modified Z-score** (Модифицированный Z-score), основанного на медиане и медианном абсолютном отклонении (MAD), которые абсолютно устойчивы (robust) к выбросам:
> $$M_i = \frac{0.6745 \cdot (x_i - \tilde{x})}{\text{MAD}}$$
> где $\tilde{x}$ --- медиана выборки, а $\text{MAD} = \text{median}(|x_i - \tilde{x}|)$.
> Порог отсечения для модифицированного Z-score обычно устанавливают равным $|M_i| > 3.5$.

### StandardScaler

`StandardScaler` из библиотеки `scikit-learn` реализует Z-преобразование для каждого признака независимо. Он центрирует данные ($\mu = 0$) и масштабирует их до единичной дисперсии ($\sigma = 1$).

*   **Где применять**: Линейная и логистическая регрессия (особенно с регуляризацией Ridge/Lasso), метод опорных векторов (SVM), метод k-ближайших соседей (k-NN), метод главных компонент (PCA).
*   **Где НЕЛЬЗЯ применять**:
    *   *Разреженные матрицы (Sparse matrices)*: Вычитание среднего значения $\mu$ превращает нулевые элементы матрицы в ненулевые, что моментально уничтожает свойство разреженности и приводит к переполнению оперативной памяти. **Решение**: Использовать `StandardScaler(with_mean=False)` (масштабирует дисперсию, не сдвигая среднее).

### MinMaxScaler

Формула масштабирования `MinMaxScaler`:
$$x_{new} = \frac{x - x_{min}}{x_{max} - x_{min}} \cdot (max\_val - min\_val) + min\_val$$
По умолчанию преобразует данные в диапазон $[0, 1]$.

*   **Где применять**: 
    *   Нейронные сети (особенно на входах с функциями активации Sigmoid или Tanh).
    *   Обработка изображений (масштабирование пикселей из диапазона $0-255$ в диапазон $0-1$).
    *   Алгоритмы, где необходимо строго сохранить разреженность данных (нули остаются нулями).
*   **Где НЕЛЬЗЯ применять**:
    *   *Наличие сильных выбросов*: Если в выборке есть одно гигантское значение $x_{max}$, все «здоровые» значения сожмутся в узкий отрезок вблизи нуля (например, $[0, 0.001]$). Это практически уничтожает полезную информацию в данном признаке.

### Логарифмическое преобразование (Log-transform)

Применяется в виде функций $y = \log(x)$ или $y = \log(x + 1)$ (`np.log1p` для предотвращения неопределенности $\log(0)$).

*   **Эффекты преобразования**:
    1.  *Сжатие масштаба*: Устраняет правостороннюю асимметрию распределения (длинные «хвосты» больших значений).
    2.  *Стабилизация дисперсии*: Борется с гетероскедастичностью (когда дисперсия ошибки зависит от значений признаков).
    3.  *Линеаризация*: Превращает мультипликативные связи признаков в аддитивные ($\log(a \cdot b) = \log(a) + \log(b)$).
*   **Где применять**: Финансовые признаки (доходы, цены квартир), счетчики (количество кликов, просмотров), физические величины с экспоненциальным ростом.
*   **Где НЕЛЬЗЯ применять**:
    *   Отрицательные значения (логарифм не определен).
    *   Распределения с левосторонней асимметрией (логарифмирование сделает хвост распределения еще более вытянутым влево).

## 3. Меры связи и статистические критерии

### Корреляция: Пирсон, Спирмен, Кендалл

#### Коэффициент линейной корреляции Пирсона ($r$)
$$r_{xy} = \frac{\sum_{i=1}^n (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_{i=1}^n (x_i - \bar{x})^2 \sum_{i=1}^n (y_i - \bar{y})^2}}$$
*   **Предпосылки**: Обе переменные непрерывны, распределены нормально, связь между ними **линейна**, отсутствуют значимые выбросы.
*   **Где НЕЛЬЗЯ использовать**:
    *   *Нелинейная связь*: Для параболической зависимости $y = x^2$ коэффициент Пирсона будет $r \approx 0$, хотя существует строгая связь.
    *   *Наличие выбросов*: Один экстремальный выброс может искусственно завысить или обнулить значение корреляции Пирсона.

#### Коэффициент ранговой корреляции Спирмена ($\rho$)
Коэффициент Спирмена --- это коэффициент Пирсона, рассчитанный для **рангов** значений:
$$\rho = 1 - \frac{6 \sum d_i^2}{n(n^2 - 1)}$$
где $d_i = \operatorname{rank}(x_i) - \operatorname{rank}(y_i)$ --- разность рангов наблюдений.
*   **Преимущества**: Нечувствителен к выбросам, не требует нормальности распределения, улавливает **любую монотонную зависимость** (даже нелинейную).

#### Коэффициент ранговой корреляции Кендалла ($\tau$)
$$\tau = \frac{C - D}{\frac{1}{2} n (n-1)}$$
где $C$ --- количество согласованных пар (когда направления изменений совпадают), $D$ --- количество несогласованных пар.
*   **Свойства**: Более консервативен, чем коэффициент Спирмена. Считается более надежным на выборках малого объема с большим количеством одинаковых рангов.

```python
import numpy as np
from scipy import stats

x = np.array([1, 2, 3, 4, 100]) # выброс на конце
y = np.array([2, 4, 6, 8, 10])

pearson_r, p_val_p = stats.pearsonr(x, y)     # Сильно исказится выбросом (r ~ 0.58)
spearman_rho, p_val_s = stats.spearmanr(x, y) # Устойчив к выбросу (rho = 1.0)
kendall_tau, p_val_k = stats.kendalltau(x, y) # Устойчив к выбросу (tau = 1.0)
```

### Параметрические критерии проверки гипотез

#### t-критерий Стьюдента

1.  **Одновыборочный (One-sample t-test)**:
    $$t = \frac{\bar{X} - \mu_0}{s / \sqrt{n}}$$
2.  **Двухвыборочный независимый (Independent two-sample t-test)**:
    $$t = \frac{\bar{X}_1 - \bar{X}_2}{\sqrt{\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}}}$$
    *Примечание*: Это формула для **t-критерия Уэлча (Welch's t-test)**, используемого по умолчанию при неравенстве дисперсий ($\sigma_1^2 \neq \sigma_2^2$).
3.  **Парный (Paired t-test)**: Сравнение одной группы до и после воздействия. Эквивалентен одновыборочному t-тесту для разностей $d_i = x_{i,\text{after}} - x_{i,\text{before}}$.

**Предпосылки t-критерия**:
1.  *Нормальность распределения* исходных данных в группах.
    *   *ЦПТ*: При объемах выборки $n_1, n_2 > 30$ t-критерий устойчив к отклонениям от нормальности, так как выборочные средние будут распределены нормально в силу Центральной Предельной Теоремы.
2.  *Независимость*: Наблюдения независимы.
3.  *Гомоскедастичность*: Равенство дисперсий (иначе использовать t-критерий Уэлча).

**Где НЕЛЬЗЯ использовать t-критерий**:
*   Малые выборки ($n < 30$) со значительным отклонением от нормальности (сильная асимметрия, бимодальность).
*   Наличие тяжелых выбросов (снижают статистическую мощность).
*   Качественные или порядковые данные.

```python
# Двухвыборочный t-критерий Уэлча (разные дисперсии)
t_stat, p_val = stats.ttest_ind(group_a, group_b, equal_var=False)

# Парный t-критерий
t_stat_paired, p_val_paired = stats.ttest_rel(before_treatment, after_treatment)
```

### Непараметрические критерии проверки гипотез

#### Критерий Манна-Уитни (Mann-Whitney U-test)

Непараметрический аналог независимого двухвыборочного t-критерия.
*   **Принцип действия**: Объединение выборок, ранжирование всех элементов, сравнение сумм рангов.
*   **Нулевая гипотеза ($H_0$)**: Вероятность того, что наблюдение из выборки $X$ больше наблюдения из выборки $Y$, равна 50%: $P(X > Y) = 0.5$.
*   **Главная ловушка для кандидатов**:
    *   *Миф*: «Критерий Манна-Уитни сравнивает медианы».
    *   *Реальность*: Тест проверяет **стохастическое доминирование**. Он сравнивает медианы **только при одинаковой форме** распределений сравниваемых групп. При разной форме тест сработает на общие сдвиги и выбросы, даже если медианы групп строго равны.
*   **Где НЕЛЬЗЯ использовать**: Связанные выборки.

```python
u_stat, p_val_mw = stats.mannwhitneyu(group_a, group_b, alternative='two-sided')
```

#### Критерий согласия хи-квадрат ($\chi^2$)

Используется для категориальных данных.
$$\chi^2 = \sum_{i=1}^k \frac{(O_i - E_i)^2}{E_i}$$
где $O_i$ --- наблюдаемая частота (Observed), $E_i$ --- ожидаемая частота (Expected) при истинности $H_0$.

**Предпосылки**:
1.  Независимость наблюдений.
2.  Объем выборки достаточен: ожидаемые частоты во **всех** ячейках не менее 5 ($E_i \ge 5$).

**Где НЕЛЬЗЯ использовать**:
*   Малые выборки, где ожидаемое количество наблюдений хотя бы в одной ячейке таблицы сопряженности меньше 5. **Решение**: Использовать *Точный критерий Фишера* (для таблиц $2 \times 2$).
*   Зависимые выборки. **Решение**: Применять *Критерий МакНемара*.

```python
# Таблица сопряженности: [[A_converted, A_not_converted], [B_converted, B_not_converted]]
table = [[120, 880], [165, 835]]
chi2, p_val, dof, expected = stats.chi2_contingency(table)
```

#### Критерий Колмогорова-Смирнова (KS-test)

Универсальный метод сравнения законов распределения.
Статистика критерия $D$ --- максимальное вертикальное расстояние между эмпирическими CDF:
$$D = \sup_x |F_1(x) - F_2(x)|$$

**Предпосылки и ограничения**:
1.  *Непрерывность*: Переменная должна быть строго непрерывной. На дискретных данных (рейтинги в звездах 1--5) критерий становится слишком консервативным (завышает p-value).
2.  В одновыборочном тесте параметры теоретического распределения не должны оцениваться по исследуемой выборке. Если вы проверяете на нормальность и берете среднее/std выборки в качестве параметров теоретического распределения --- стандартный KS-test использовать **нельзя**. **Решение**: Использовать *Критерий Лиллиефорса*.

```python
# Сравнение распределений двух групп пользователей
d_stat, p_val_ks = stats.ks_2samp(group_a, group_b)
```

### Дополнительные статистические тесты (Собеседование уровня Senior)

#### Проверка нормальности: Критерий Шапиро-Уилка (Shapiro-Wilk)
Самый мощный критерий проверки нормальности для малых/средних выборок ($n < 5000$).
*   `stats.shapiro(data)`
*   *Подводный камень*: На сверхбольших выборках ($n > 100\,000$) критерий отклоняет гипотезу нормальности даже при незначительных, практически неважных отклонениях. На больших данных лучше использовать Q-Q Plot.

#### Дисперсионный анализ (ANOVA) и Критерий Краскела-Уоллиса
*   **ANOVA (F-test)**: Параметрическое сравнение средних для 3+ независимых групп. Требует нормальности и гомоскедастичности.
    *   `stats.f_oneway(g1, g2, g3)`
*   **Критерий Краскела-Уоллиса (Kruskal-Wallis)**: Непараметрический аналог ANOVA для сравнения 3+ групп.
    *   `stats.kruskal(g1, g2, g3)`

#### Связанные выборки: Критерий знаковых рангов Уилкоксона
Непараметрический аналог парного t-критерия для зависимых выборок.
*   `stats.wilcoxon(before, after)`

#### Проверка равенства дисперсий: Критерии Бартлетта и Ливеня
Проверяют гомоскедастичность перед t-тестом или ANOVA:
*   **Критерий Бартлетта**: Высокая мощность, но **крайне чувствителен** к ненормальности данных.
    *   `stats.bartlett(group_a, group_b)`
*   **Критерий Ливеня (Levene's test)**: Устойчив к отклонениям от нормальности (robust). Рекомендуется использовать по умолчанию.
    *   `stats.levene(group_a, group_b, center='median')`

#### Точный критерий Фишера (Fisher's Exact Test)
Используется вместо $\chi^2$ для анализа таблиц сопряженности $2 \times 2$, когда хотя бы одна ожидаемая частота ячейки $< 5$. Вычисляет точную вероятность по гипергеометрическому распределению.
*   `odds_ratio, p_val = stats.fisher_exact(table)`

## 4. Контекст A/B-тестирования, p-value и множественное тестирование

### Глубокое понимание p-value

> [!IMPORTANT]
> **Строгое математическое определение**:
> `p-value` --- это вероятность получить наблюдаемое значение тест-статистики (или еще более экстремальное) при условии, что нулевая гипотеза $H_0$ верна:
> $$p\text{-value} = P(T(X) \ge T(x_{obs}) \mid H_0)$$

#### Четыре главных заблуждения на собеседованиях:

1.  **Заблуждение**: «p-value --- это вероятность того, что нулевая гипотеза верна».
    *   **Истина**: В частотном подходе гипотеза не является случайной величиной (она либо верна, либо нет). p-value --- это условная вероятность данных при гипотезе $P(\text{данные} \mid H_0)$, а не $P(H_0 \mid \text{данные})$.
2.  **Заблуждение**: «p-value --- это вероятность совершить ошибку I рода ($\alpha$)».
    *   **Истина**: Уровень значимости $\alpha$ задается **до** эксперимента как постоянный порог. p-value --- случайная величина, рассчитываемая **после** эксперимента по фактическим данным.
3.  **Заблуждение**: «Маленький p-value указывает на большую величину продуктового эффекта».
    *   **Истина**: На гигантских объемах данных даже ничтожный эффект получит крошечный p-value. Для оценки практической важности эффекта всегда рассчитывают точечный эффект и его доверительные интервалы.
4.  **Заблуждение**: «Если $p\text{-value} > \alpha$, нулевая гипотеза доказана как верная».
    *   **Истина**: Это означает лишь то, что у нас недостаточно мощности или доказательств, чтобы её отклонить. Отсутствие доказательств эффекта не является доказательством его отсутствия.

### Ошибки при проверке гипотез и расчет выборки

*   **Ошибка I рода ($\alpha$)**: Вероятность отклонить $H_0$, когда она верна (ложная тревога). Обычно фиксируется на уровне $\alpha = 0.05$.
*   **Ошибка II рода ($\beta$)**: Вероятность НЕ отклонить $H_0$, когда она ложна (упущенная выгода). Обычно фиксируется на уровне $\beta = 0.20$.
*   **Статистическая мощность ($1 - \beta$)**: Вероятность обнаружить реальный эффект, если он существует. Стандартный уровень --- не менее 80%.
*   **MDE (Minimum Detectable Effect)**: Минимальный эффект изменения метрики, который мы хотим гарантированно зафиксировать в эксперименте.

Формула объема выборки $N$ (для одной группы в тесте на равенство средних):
$$N \approx \frac{2 \sigma^2 \cdot (Z_{1-\alpha/2} + Z_{1-\beta})^2}{\text{MDE}^2}$$
где $\sigma^2$ --- дисперсия целевой метрики, $Z$ --- квантили нормального распределения.

> [!TIP]
> Размер выборки прямо пропорционален дисперсии метрики ($\sigma^2$) и обратно пропорционален квадрату MDE. Для сокращения длительности экспериментов используют методы снижения дисперсии: CUPED, стратификацию или отсечение выбросов.

### Проблема множественного тестирования (Multiple Testing)

При одновременной проверке нескольких гипотез (сравнение 1 контроля и 5 тестовых вариантов или замер 10 разных метрик) резко возрастает вероятность получить ложноположительный результат просто за счет случайного шума.

Если проверяется $k$ независимых гипотез на уровне $\alpha$, групповая вероятность совершить хотя бы одну ошибку I рода (FWER) равна:
$$\text{FWER} = 1 - (1 - \alpha)^k$$
Для $k = 10$ и $\alpha = 0.05$: $\text{FWER} = 1 - 0.95^{10} \approx 40\%$ (вместо целевых 5%!).

**Методы борьбы с множественным сравнением**:
1.  **Поправка Бонферрони (Bonferroni correction)**:
    Делим целевой уровень $\alpha$ на количество сравнений $k$:
    $$\alpha_{new} = \frac{\alpha}{k}$$
    *   *Плюсы*: Предельная простота.
    *   *Минусы*: Слишком консервативна, сильно занижает мощность (особенно при высокой корреляции между метриками).
2.  **Метод Бенджамини-Хохберга (FDR --- False Discovery Rate)**:
    Контролирует ожидаемую долю ложных отклонений среди всех отклоненных гипотез. Менее консервативен и сохраняет гораздо больше мощности.
    *   Полученные $p\text{-values}$ сортируются по возрастанию: $p_{(1)} \le p_{(2)} \le \dots \le p_{(k)}$.
    *   Находим наибольшее $i$, для которого выполняется условие:
        $$p_{(i)} \le \frac{i}{k} \cdot Q$$
        где $Q$ --- целевой уровень FDR (например, 0.05).
    *   Отклоняем все гипотезы от $1$ до $i$.

```python
from statsmodels.stats.multitest import multipletests

p_values = [0.005, 0.012, 0.03, 0.045, 0.12]

# Поправка Бонферрони
reject_bonf, corrected_p_bonf, _, _ = multipletests(p_values, alpha=0.05, method='bonferroni')

# Контроль FDR методом Бенджамини-Хохберга
reject_fdr, corrected_p_fdr, _, _ = multipletests(p_values, alpha=0.05, method='fdr_bh')
```

## 5. Итоговая шпаргалка: Выбор статистического критерия

| **Тип данных** | **Параметрический критерий (нормальность, $N > 30$)** | **Непараметрический критерий (любое распределение, выбросы)** |
| :--- | :--- | :--- |
| **2 независимые группы** (метрический признак, e.g., средний чек) | **t-критерий Стьюдента** (при равенстве дисперсий) или **t-критерий Уэлча** (`equal_var=False`) | **Критерий Манна-Уитни** (проверяет стохастическое доминирование) |
| **2 зависимые группы** (метрический признак, e.g., «до» и «после») | **Парный t-критерий Стьюдента** | **Критерий знаковых рангов Уилкоксона** |
| **3+ независимые группы** (метрический признак) | **Однофакторный ANOVA** (F-test) | **Критерий Краскела-Уоллиса** |
| **Категориальные данные** (качественный признак, e.g., конверсия) | **Z-критерий долей** (при больших выборках) | **Критерий хи-квадрат ($\chi^2$)** (ожидаемые частоты $\ge 5$) или **Точный критерий Фишера** (для малых выборок) |
| **Проверка формы распределения** | **Критерий Шапиро-Уилка** (нормальность, $N < 5000$) | **Критерий Колмогорова-Смирнова** (сопоставление непрерывных функций ECDF) |

> [!IMPORTANT]
> **Antigravity: Рекомендация для собеседований**
> На собеседованиях по A/B-тестированию всегда начинайте ответ с формулировки нулевой ($H_0$) и альтернативной ($H_a$) гипотез. Затем обязательно озвучивайте предпосылки (assumptions) выбранного теста и то, как вы будете их проверять (например, тест Ливеня для дисперсий, Q-Q Plot для нормальности). Это сразу выделит вас как глубокого специалиста, который понимает математическую природу методов, а не просто вызывает стандартные библиотечные функции.
