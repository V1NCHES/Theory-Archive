# Краткий справочник: Линейные модели

Данный документ представляет собой сжатую выжимку основных концепций из подробного руководства по линейным моделям.

## 1. Типология задач
- **Регрессия:** Прогноз вещественного числа (MSE, MAE).
- **Классификация:** Разделение на классы (Accuracy, F1, ROC-AUC).
- **Ранжирование:** Восстановление порядка объектов (nDCG).

## 2. Математические основы
- **МНК (OLS):** Решение через нормальное уравнение $\omega = (X^TX)^{-1}X^Ty$.
- **QR-разложение:** Численно стабильный способ решения МНК.
- **Градиентный спуск (GD):** Итеративный поиск минимума: $w_{t+1} = w_t - \eta \nabla Q$.

## 3. Подготовка данных и Интерпретация
- **OHE:** Кодирование категорий. Важно удалять один столбец для избегания Dummy Trap.
- **Интерпретируемость:** Веса $\omega_i$ показывают вклад признака (при условии нормализации).
- **Ограничения:** Линейность, чувствительность к выбросам, мультиколлинеарность.

## 4. Оптимизация и Регуляризация
- **SGD / Mini-batch:** Обучение на частях данных для скорости.
- **L2 (Ridge):** Штраф за квадраты весов. Борется с мультиколлинеарностью.
- **L1 (Lasso):** Штраф за модули весов. Выполняет отбор признаков (зануляет веса).

## 5. Классификация
- **Логистическая регрессия:** Использование сигмоиды и Log-Loss. Выводится через метод максимального правдоподобия (MLE).
- **SVM:** Минимизация Hinge Loss, максимизация разделяющего зазора (Margin).
- **Многоклассовая:** Использование Softmax и Cross-Entropy. Стратегии OvR (1-vs-All) и OvO (1-vs-1).

## 6. Kernel Trick (Ядерный переход)
- Позволяет работать в нелинейных пространствах через замену скалярного произведения на ядро $K(x, y)$.
- **Популярные ядра:** RBF (Гауссово), Полиномиальное, Линейное.
- **KDE:** Ядерная оценка плотности распределения.
