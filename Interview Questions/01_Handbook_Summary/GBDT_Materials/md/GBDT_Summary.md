# Ансамбли и Градиентный Бустинг: Темы и вопросы

## Основные темы
1. **Bias-Variance Decomposition**
   - Ошибка = Смещение (Bias) + Разброс (Variance) + Шум.
   - **Бэггинг** (Bagging): Усреднение ответов независимых моделей. Основная цель — **уменьшение разброса**.
   - **Бустинг** (Boosting): Последовательное исправление ошибок. Основная цель — **уменьшение смещения**.

2. **Случайный лес (Random Forest)**
   - Комбинация бэггинга и метода случайных подпространств (random subspaces).
   - Бутстреп (Bootstrap): Выборка $N$ объектов с возвращением. ~63.2% уникальных объектов попадают в выборку.
   - **Out-of-bag (OOB) error**: Оценка качества на объектах, не попавших в бутстреп-выборку (бесплатная валидация).
   - Гиперпараметры: $n = \sqrt{N}$ признаков для классификации, $n = N/3$ для регрессии.

3. **Градиентный бустинг (GBDT)**
   - Градиентный спуск в пространстве функций. Обучение на антиградиент функции потерь (остатки).
   - **Shrinkage (Learning Rate)**: Замедление обучения для лучшей обобщающей способности.
   - Реализации: XGBoost (вторые производные), LightGBM (GOSS, EFB, Leaf-wise), CatBoost (Ordered Boosting, категориальные фичи).

4. **Стекинг (Stacking)**
   - Использование метамодели над предсказаниями базовых алгоритмов.
   - Обучение на **Out-of-fold** предсказаниях (через кросс-валидацию) для предотвращения переобучения метамодели.

## Вопросы для интервью
1. **Почему Random Forest не переобучается при увеличении числа деревьев?**
   - *Ответ*: Усреднение независимых моделей с одинаковым смещением не меняет смещение ансамбля, но уменьшает разброс. Ошибка выходит на плато.

2. **Что такое 63.2% в бутстрепе?**
   - *Ответ*: Вероятность того, что объект НЕ попадет в выборку при $N \to \infty$ равна $1/e \approx 0.368$. Значит, попадет $1 - 1/e \approx 0.632$.

3. **В чем разница между градиентным бустингом и AdaBoost?**
   - *Ответ*: AdaBoost меняет веса объектов (экспоненциальный лосс), а GBDT минимизирует произвольную дифференцируемую функцию потерь, аппроксимируя ее градиент.

4. **Зачем нужен стекинг, если есть бустинг?**
   - *Ответ*: Стекинг позволяет объединять модели разной природы (например, KNN и Линейную регрессию), выучивая, в каких областях данных какая модель ошибается.
