# Подбор гиперпараметров: Темы и вопросы для подготовки

## Основные темы
1. **Базовые стратегии**
   - **Grid Search**: Полный перебор по сетке. Плюсы: надежность. Минусы: "проклятие размерности", неэффективность при неважных параметрах.
   - **Random Search**: Случайный выбор из распределений. Часто лучше Grid Search, так как чаще попадает в важные области.

2. **Байесовская оптимизация (Bayesian Optimization)**
   - Идея суррогатной модели (Gaussian Processes, TPE).
   - Acquisition functions (Expected Improvement, UCB).
   - Инструменты: Optuna, Hyperopt, Scikit-Optimize.

3. **Современные ускоренные методы**
   - **Successive Halving**: Отсеивание плохих конфигураций на ранних стадиях.
   - **Hyperband**: Комбинация Random Search и Halving.

4. **Особенности валидации**
   - Переобучение под валидацию при слишком долгом поиске.
   - Важность фиксации Random Seed.

## Вопросы для интервью
1. **Почему Random Search часто лучше Grid Search?**
   - *Ответ*: В многомерном пространстве параметров некоторые из них могут почти не влиять на результат. Random Search позволяет проверить больше уникальных значений важных параметров.

2. **Как работает библиотека Optuna?**
   - *Ответ*: Использует алгоритм TPE (Tree-structured Parzen Estimator) для умного выбора следующих параметров и механизмы Pruning (прекращение бесперспективных испытаний).

3. **Что делать, если подбор параметров занимает слишком много времени?**
   - *Ответ*: Использовать уменьшенную выборку (subsampling), сократить пространство поиска, применить Hyperband или начать с предобученных параметров (Transfer Learning).

4. **В чем разница между параметрами и гиперпараметрами?**
   - *Ответ*: Параметры модель учит сама (веса в регрессии), а гиперпараметры задает человек до начала обучения (глубина дерева, C в SVM).
