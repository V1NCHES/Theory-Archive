# LeetCode Theory & Solutions

Репозиторий содержит структурированные материалы для подготовки к техническим собеседованиям по алгоритмам и структурам данных на платформе LeetCode.

## 📋 Оглавление

1. [**01. Массивы (Arrays)**](01_Arrays.ipynb) — Основные операции, задачи на два указателя и префиксные суммы.
2. [**02. Строки (Strings)**](02_Strings.ipynb) — Алгоритмы обработки строк, палиндромы, анаграммы.
3. [**03. Хэш-таблицы (Hash Tables)**](03_HashTables.ipynb) — Быстрый поиск, подсчет частот элементов.
4. [**04. Стеки (Stacks)**](04_Stacks.ipynb) — Принцип LIFO, задачи на правильные скобочные последовательности.
5. [**05. Очереди (Queues)**](05_Queues.ipynb) — Принцип FIFO, использование `deque`.
6. [**06. Кучи и Очереди с приоритетом (Heaps & Priority Queues)**](06_Heaps_PriorityQueues.ipynb) — Min-Heap/Max-Heap, поиск K-го наибольшего элемента.
7. [**07. Жадные алгоритмы (Greedy)**](07_Greedy.ipynb) — Поиск локально оптимального решения.
8. [**08. Динамическое программирование (Dynamic Programming)**](08_DynamicProgramming.ipynb) — Оптимизация задач через подзадачи.

---

## 🚀 Как использовать
Каждый ноутбук содержит:
- Краткую теоретическую справку.
- Временную и пространственную сложность операций.
- Примеры реализации на Python.
- Ссылки на популярные задачи LeetCode для практики.
