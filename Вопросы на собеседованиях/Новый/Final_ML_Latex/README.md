# Master ML Study Handbook: Deep Dive into Machine Learning

Этот репозиторий содержит полный справочник по машинному обучению, структурированный для глубокого изучения теории и подготовки к техническим собеседованиям.

## Содержание курса

1.  **Линейные модели**: МНК, регуляризация (L1/L2), логистическая регрессия, QR/SVD разложения.
2.  **Метрики качества**: Офлайн/онлайн метрики, ROC-AUC, PR-AUC, матрица ошибок, SMAPE/WAPE.
3.  **Кросс-валидация**: Hold-out, k-Fold, стратификация, утечки данных (Data Leakage).
4.  **Метрические методы**: k-NN, ядерное сглаживание, ANN (LSH, HNSW).
5.  **Подбор гиперпараметров**: Grid Search, Random Search, Байесовская оптимизация, PBT.
6.  **Решающие деревья**: Энтропия, критерий Джини, жадный алгоритм, гистограммный метод.
7.  **Градиентный бустинг**: GBDT, математика антиградиента, XGBoost, LightGBM, CatBoost.

## Структура файлов

*   `Master_ML_Study.tex`: Главный файл сборки справочника.
*   `Master_ML_Study.pdf`: Скомпилированная версия справочника (27 страниц).
*   `*.tex`: Отдельные модули по каждой теме (автономные копии).
*   `*.png`: Иллюстрации и визуализации к материалам.

## Как собрать документ

Для сборки PDF из исходников используйте PDFLaTeX:

```bash
pdflatex Master_ML_Study.tex
```
(Может потребоваться 2-3 запуска для корректного отображения оглавления).
