# 📘 Заметки для подготовки (Interview Prep Notes)

Комплексные материалы для подготовки к собеседованиям по различным техническим секциям. Собраны ключевые темы, которые чаще всего встречаются на интервью.

## 📋 Содержание

1. [**01 Data Analysis**](01_Data_Analysis.ipynb) — EDA, визуализация данных, проверка гипотез и статистика.
2. [**02 Machine Learning**](02_Machine_Learning.ipynb) — Теоретические вопросы по алгоритмам и ML System Design.
3. [**03 MLOps**](03_MLOps.ipynb) — Деплой моделей, мониторинг, CI/CD для ML и работа с данными в проде.
4. [**04 Development Tools**](04_Development_Tools.ipynb) — Работа в терминале, Git, Docker и окружения.
5. [**05 Data Engineering & SQL**](05_Data_Engineering_SQL.ipynb) — Проектирование БД, ETL-процессы и сложные SQL-кейсы.
6. [**06 Python Interview**](06_Python_Interview.ipynb) — Особенности языка: GIL, декораторы, генераторы, асинхронность и структуры данных.

---
*Материалы структурированы для быстрого повторения перед собеседованием.*
