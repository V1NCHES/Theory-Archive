# 🤖 Machine Learning (ML)

Подробные лекции и практические примеры по классическому машинному обучению. Охватывают весь путь от сбора данных до выбора и оптимизации финальной модели.

## 📋 Содержание

1. [**01 Вводная**](01_Вводная.ipynb) — Основные понятия, типы обучения и постановка задач.
2. [**02 Методология ML**](02_Методология_ML.ipynb) — Жизненный цикл разработки, валидация и пайплайны.
3. [**03 Метрические методы**](03_Метрические_методы.ipynb) — k-NN, расстояния и веса.
4. [**04 Линейные модели**](04_Линейные_модели.ipynb) — Регрессия, классификация, регуляризация (L1/L2).
5. [**05 Ядерные методы**](05_Ядерные_методы.ipynb) — SVM и Kernel Trick.
6. [**06 Решающие деревья**](06_Решающие_деревья.ipynb) — Алгоритмы построения, критерии информативности и стрижка.
7. [**07 Ансамбли**](07_Ансамбли.ipynb) — Бэггинг, бустинг (XGBoost, CatBoost, LightGBM) и случайный лес.
8. [**08 Метрики качества**](08_Метрики_качества.ipynb) — MSE, MAE, R2, Accuracy, Precision, Recall, F1, ROC-AUC.
9. [**09 Снижение размерности**](09_Снижение_размерности.ipynb) — PCA, t-SNE, UMAP.
10. [**10 Кластеризация**](10_Кластеризация.ipynb) — K-means, DBSCAN, иерархическая кластеризация.
11. [**11 Оптимизация гиперпараметров**](11_Оптимизация_гиперпараметров.ipynb) — Grid Search, Random Search, Optuna.
12. [**12 Нейронные сети**](12_Нейронные_сети.ipynb) — Введение в многослойные перцептроны в контексте классического ML.
