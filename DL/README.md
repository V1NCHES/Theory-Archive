# 🧠 Deep Learning (DL)

Этот раздел содержит материалы курса по нейронным сетям и глубокому обучению. Здесь разобраны как фундаментальные основы, так и современные архитектуры для CV и NLP.

## 📋 Содержание

1. [**01 Введение в нейросети**](01_Введение_в_нейросети.ipynb) — Основы перцептрона, функции активации и метод обратного распространения ошибки.
2. [**02 PyTorch**](02_PyTorch.ipynb) — Работа с тензорами, создание слоев и тренировочные циклы.
3. [**03 Нормализация**](03_Нормализация.ipynb) — Batch Normalization, Layer Normalization и их влияние на обучение.
4. [**04 CNN**](04_CNN.ipynb) — Сверточные нейронные сети для компьютерного зрения.
5. [**05 Transfer Learning**](05_Transfer_Learning.ipynb) — Использование предобученных моделей и Fine-tuning.
6. [**06 Word Embeddings**](06_Word_Embeddings.ipynb) — Векторные представления слов: Word2Vec, GloVe.
7. [**07 RNN**](07_RNN.ipynb) — Рекуррентные сети для последовательностей (LSTM, GRU).
8. [**08 Language Models**](08_Language_Models.ipynb) — Вероятностные модели языка и метрика Perplexity.
9. [**09 Attention**](09_Attention.ipynb) — Механизм внимания и основы архитектуры Transformer.
10. [**10 Detection & Segmentation**](10_Detection_Segmentation.ipynb) — Обнаружение объектов и семантическая сегментация.
11. [**11 Generative Models**](11_Generative_Models.ipynb) — Генеративно-состязательные сети (GAN) и автокодировщики (VAE).

---
*Все материалы представлены в формате Jupyter Notebook для удобства экспериментов.*
